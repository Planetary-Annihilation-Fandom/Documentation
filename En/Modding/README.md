## Software

No additional software is required, but these tools can make mod development easier.

### Coherent Debugger

The debugger lets you inspect the game interface like a browser. The game client is a subset of a browser and uses the same technologies. Add `--coherent_port=9999` to the game's launch options so the debugger can connect.

[Download Coherent UI Debugger for Windows](https://cdn.planetaryannihilation.com/downloads/debugger-windows.zip)

### Blender plugin

[Blender-PAPA-IO](https://github.com/Luther-1/Blender-PAPA-IO/releases) is a Blender Python extension for importing and exporting model, texture, and animation data in Planetary Annihilation's `.PAPA` format. The wiki recommends it for both import and export.

### Visual Studio Code

The wiki recommends [Visual Studio Code](https://code.visualstudio.com/) for editing mods.
